# Mood Cafe & Lounge Bar Website

A static website for **Mood Cafe & Lounge Bar**, a cafe and lounge concept in Infanta, Quezon. The site presents the cafe's atmosphere, menu highlights, live music/events, and hiring information in a polished single-page layout.

## Features

- Responsive landing page for Mood Cafe & Lounge Bar
- Top navigation for Home, Menu, Music, and Jobs sections
- Hero section with cafe highlights, hours, location, and contact links
- Menu gallery featuring coffee, matcha, meals, snacks, cocktails, and drinks
- Live music and events section with weekly programme details
- Jobs section with current openings and application information
- Local image assets for menu items, events, team photos, and branding

## Project Structure

```text
mood_cafe_website-main/
+-- index.html          # Main website markup and section navigation script
+-- style.css           # Styling, layout, responsive design, and visual theme
+-- README.md           # Project documentation
+-- logo.png            # Brand logo
+-- background.png      # Main hero background
+-- *.jpg / *.png       # Menu, event, team, and cafe image assets
```

> Note: This project currently keeps image assets in the root folder alongside the HTML and CSS files.

## How to Run

No build step or package installation is required.

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. Use the navigation bar to switch between the Home, Menu, Music, and Jobs sections.

## Main Files

- `index.html` contains the page content, navigation, section layout, and simple JavaScript for switching views.
- `style.css` contains the full visual design, including colors, spacing, layout, cards, navigation, and responsive behavior.
- Image files such as `logo.png`, `background.png`, `coffee.png`, `meals.jpg`, `events.jpg`, and menu images provide the site's visual content.

## Sections

### Home

Introduces Mood Cafe & Lounge Bar with the brand logo, tagline, cafe description, weekend special, highlights, opening hours, location, and contact details.

### Menu

Shows featured food and drink categories, including coffee, matcha, milkshakes, meals, snacks, alcoholic drinks, and cocktails.

### Music

Highlights live performances, games, celebrations, art events, and the weekly music programme.

### Jobs

Lists current openings such as barista/cafe staff, bartender/mixologist, service crew, content creator, and events coordinator.
